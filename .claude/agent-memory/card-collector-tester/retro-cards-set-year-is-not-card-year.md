Modern sets carry retired players constantly (Archives, Heritage, A&G legends, "3X MVP"-style subsets). For them:
- The set year matches no stint, so career suggestions fall back to the whole career; copy must not say "this card's year" as if the player were active — name the set year ("No 2025 team on file").
- Two cards of one legend in one set can show different teams by design (a career-moment subset: Foxx MVPs 1932/33 A's, 1938 Red Sox). A "same player in this set" fill is a guess, never "this set says".

**Why:** NEO-330 copy review (2026-10-11) — the Fill conflict row called a copied-from-#36 team "this set says".
**How to apply:** any copy that attributes a team to "the set" or "the card's year" — require it to name the real source (the other card number, the rule) instead. See [[twin-names-copy-review]].

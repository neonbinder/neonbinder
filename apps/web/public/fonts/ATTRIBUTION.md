# Spine label typefaces

The fonts in this directory are used by the binder spine label designer
(`/print/spine-label`, NEO-147). Each is subset to Latin, Latin-1 Supplement
and Latin Extended-A, and converted to WOFF2; the variable fonts are pinned to
a single heavy weight. The originals are unmodified beyond that — no glyphs
were redrawn and no font was renamed.

Both licences permit embedding, redistribution and commercial use, which is
why these were chosen. Note that the OFL requires this notice to travel with
the font files, so **do not delete this file when moving them**.

## Reserved Font Names

Graduate, Squada and Titan One carry Reserved Font Names under the OFL. That
matters only if a *modified* version is redistributed — a subset is not a
rename, and none of these are renamed here. If one is ever genuinely modified,
it must be released under a different name.

## What is deliberately NOT here

Recreations of real team wordmarks — the kind found on font aggregator sites.
Those sites typically grant no licence at all and disclaim any affiliation,
and the lettering in a team's wordmark is a trademark owned by the club
regardless of who uploaded a copy of the file. Team COLOURS are facts and are
used freely; team LETTERING is a mark and is not.
